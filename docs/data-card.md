# Data card

See [Dataset](dataset.md) for source, schema and filtering. The current UI uses a small authored synthetic fixture file embedded in the application. Fixture values are for exercising UI states and are not sampled from WildChat or model evaluations. There are no persisted raw transcripts or corpus results in the repository.

If real processed data is added locally, keep raw/processed outputs ignored by Git, preserve the source commit SHA and sampling metadata, and review privacy and license obligations before sharing derived examples.

# Research methodology

The primary unit is a request-response pair with only preceding context. Retrospective response classification is distinct from research into pre-response request characteristics. Avoid user-facing tools that estimate individualized refusal likelihood or help bypass safeguards.

Separate evidence as: observed corpus outcomes, human-reviewed outcomes, classifier estimates validated on an independent benchmark, and synthetic interface examples. Each empirical statistic needs a denominator, sampling definition, source revision, annotation/model provenance, and uncertainty. Use grouped splits by conversation and check near-duplicates/templates across splits. Report temporal and language-specific performance when sample sizes allow.

WildChat is filtered and observational. Its moderation metadata, response explanations, and historical model IDs are not causal evidence. Population claims should describe the sample and its selection explicitly. Unnecessary refusal is an adjudicated human judgment, never a direct classifier output.

This repository currently has no completed WildChat processing run, human-reviewed corpus, trained model, embedding/clustering artifact, or empirical analysis.

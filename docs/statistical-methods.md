# Statistical methods

For a proportion with a defensible sampling design, report numerator, denominator and a Wilson interval. For multiple pairs per conversation, use conversation-clustered bootstrap intervals. Apply sampling weights when known; retain selection probabilities and separate enriched development samples from representative samples.

Comparisons are observational. Adjusting for measured language, domain, time, request characteristics and conversation length can reduce measured imbalance, but does not establish causal effects. Report standardized differences, effect sizes, missingness and sensitivity analyses. Use permutation tests and multiplicity correction only with a predeclared comparison family. Suppress unstable small-cell comparisons.

No confidence intervals or research estimates are calculated from the synthetic fixtures as corpus findings. No benchmark metrics exist until a labeled, versioned, conversation-grouped split has been evaluated.

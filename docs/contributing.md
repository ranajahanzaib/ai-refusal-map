# Contributing

Keep synthetic demo content clearly labeled. Do not add real conversations, private annotations, model weights or large generated artifacts to Git. Research claims require executed provenance and denominators. Taxonomy changes should be versioned and documented with examples. Run Python tests, Ruff, Pyright, Biome, TypeScript checks and the production build for relevant changes.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for repository contribution conventions and [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) for community guidelines.
